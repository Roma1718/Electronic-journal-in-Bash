# Electronic Journal in Bash

Консольный электронный журнал, написанный на Bash.

Проект предназначен для управления учебными курсами, группами, студентами, оценками и посещаемостью через терминал Linux. Данные хранятся локально в CSV-файлах.

Программа поддерживает два режима работы:

- интерактивное меню;
- выполнение отдельных операций через аргументы командной строки.

## Возможности

Электронный журнал позволяет:

- регистрировать преподавателей;
- выполнять вход по логину и паролю;
- создавать и удалять учебные курсы;
- создавать и удалять группы;
- добавлять студентов;
- искать студентов по имени;
- удалять студентов;
- выставлять оценки;
- просматривать оценки;
- удалять оценки;
- отмечать пропуски занятий;
- просматривать пропуски;
- удалять пропуски;
- выполнять выборку студентов по имени;
- выполнять выборку по оценкам;
- импортировать список студентов из CSV;
- экспортировать данные группы в CSV;
- создавать резервные копии;
- вести журнал действий;
- выполнять основные операции через CLI.

## Хранение данных

Проект использует файловую структуру вместо отдельной СУБД.

Основная иерархия:

```text
Преподаватель
    │
    └── Курс
         │
         └── Группа
              │
              ├── Студенты
              ├── Оценки
              └── Пропуски
```

Для каждой группы создаются три CSV-файла.

### students.csv

Хранит идентификаторы и ФИО студентов.

Пример:

```csv
id,name
101001,Орлов Александр Игоревич
101002,Васильева Екатерина Олеговна
101003,Зайцев Дмитрий Сергеевич
```

### grades.csv

Хранит оценки студентов.

Формат:

```csv
student_id,date,grade
101001,2026-09-05,5
101001,2026-09-12,4
101002,2026-09-05,5
```

Поле `student_id` связывает оценку со студентом из `students.csv`.

### absences.csv

Хранит сведения о пропусках.

Формат:

```csv
student_id,date,status
101002,2026-09-19,нб
101003,2026-09-12,нб
```

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone git@github.com:Roma1718/Electronic-journal-in-Bash.git
```

Перейдите в каталог:

```bash
cd Electronic-journal-in-Bash
```

Разрешите выполнение главного файла:

```bash
chmod +x journal.sh
```

Запустите программу:

```bash
./journal.sh
```

## Интерактивный режим

При запуске без аргументов открывается главное меню:

```text
==========================================
          ЭЛЕКТРОННЫЙ ЖУРНАЛ
==========================================

1. Войти
2. Создать аккаунт преподавателя
0. Выход
```

После регистрации преподаватель может войти в систему.

После входа доступно управление курсами:

```text
1. Показать курсы
2. Создать курс
3. Войти в курс
4. Удалить курс
5. Создать резервную копию
0. Выйти из аккаунта
```

Внутри курса доступно управление группами:

```text
1. Показать группы
2. Создать группу
3. Войти в группу
4. Удалить группу
0. Назад
```

После выбора группы открывается основная часть электронного журнала:

```text
1. Показать студентов
2. Добавить студента
3. Найти студента
4. Удалить студента
5. Поставить оценку
6. Показать оценки
7. Удалить оценку
8. Отметить пропуск
9. Показать пропуски
10. Удалить пропуск
11. Выборка по оценке
12. Выборка по имени
13. Экспорт CSV
14. Импорт студентов из CSV
0. Назад
```

## Командный режим

Часть операций можно выполнять напрямую из терминала без открытия интерактивного меню.

Получить справку:

```bash
./journal.sh --help
```

Показать версию:

```bash
./journal.sh --version
```

Пример результата:

```text
Electronic Journal 1.0.0
```

### Просмотр студентов

```bash
./journal.sh --list-students USER COURSE GROUP
```

Пример:

```bash
./journal.sh --list-students roma "Dangen master" DGB-27
```

Пример результата:

```text
ID: 27001 | Смирнов Алексей Сергеевич
ID: 27002 | Кузнецова Анна Игоревна
ID: 27003 | Попов Максим Андреевич
ID: 27004 | Соколова Мария Дмитриевна
ID: 27005 | Лебедев Артём Олегович
```

### Поиск студента

```bash
./journal.sh --find-student USER COURSE GROUP NAME
```

Например:

```bash
./journal.sh --find-student roma "Dangen master" DGB-27 "Смирнов"
```

### Добавление студента

```bash
./journal.sh --add-student USER COURSE GROUP NAME
```

Например:

```bash
./journal.sh --add-student roma "Dangen master" DGB-27 "Иванов Иван Иванович"
```

Для нового студента автоматически генерируется уникальный идентификатор.

### Выставление оценки

```bash
./journal.sh --set-grade USER COURSE GROUP STUDENT_ID GRADE DATE
```

Например:

```bash
./journal.sh --set-grade roma "Dangen master" DGB-27 27001 5 2026-09-25
```

Допустимые оценки:

```text
2
3
4
5
```

Дата передаётся в формате:

```text
YYYY-MM-DD
```

### Добавление пропуска

```bash
./journal.sh --set-absence USER COURSE GROUP STUDENT_ID DATE
```

Например:

```bash
./journal.sh --set-absence roma "Dangen master" DGB-27 27002 2026-09-25
```

### Экспорт

```bash
./journal.sh --export USER COURSE GROUP
```

Например:

```bash
./journal.sh --export roma "Dangen master" DGB-27
```

Программа создаст отдельный каталог в `exports/` и скопирует туда:

```text
students.csv
grades.csv
absences.csv
```

## Резервное копирование

Для создания резервной копии:

```bash
./journal.sh --backup
```

Резервные копии сохраняются в каталоге:

```text
backups/
```

Формат имени:

```text
journal_backup_YYYYMMDD_HHMMSS.tar.gz
```

В архив помещается каталог с данными электронного журнала.

## Импорт CSV

В интерактивном режиме можно загрузить список студентов из CSV-файла.

Файл должен иметь заголовок:

```csv
id,name
```

Пример:

```csv
id,name
50001,Иванов Иван Иванович
50002,Петров Пётр Петрович
50003,Сидорова Анна Сергеевна
```

После импорта этот список используется как список студентов выбранной группы.

## Экспорт CSV

Экспорт создаёт копию данных выбранной группы.

В экспорт входят:

```text
students.csv
grades.csv
absences.csv
```

Это позволяет открыть данные в программах для работы с таблицами или перенести их в другую систему.

## Регистрация и авторизация

При создании преподавателя программа запрашивает:

```text
Логин
Пароль
Повтор пароля
ФИО преподавателя
```

Пароль не записывается в пользовательский файл в открытом виде.

Для него вычисляется SHA-256 хэш с помощью:

```bash
sha256sum
```

Файл пользователя имеет вид:

```text
login=example
password_hash=...
teacher_name=Иванов Иван Иванович
```

Каталог `data/users/` добавлен в `.gitignore`, поэтому локальные файлы пользователей не публикуются в Git-репозитории.

## Работа с CSV

Для обработки CSV активно используется `awk`.

Например, вывод студентов строится на основе разделителя `,`:

```bash
awk -F',' 'NR > 1 {print "ID: " $1 " | " $2}' students.csv
```

Здесь:

- `-F','` задаёт запятую как разделитель;
- `$1` означает первый столбец;
- `$2` означает второй столбец;
- `NR > 1` пропускает заголовок CSV.

Также используются `grep`, `cut` и другие стандартные инструменты Linux.
