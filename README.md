# Электронный журнал

Учебный проект по операционным системам.

Программа представляет собой электронный журнал преподавателя, реализованный на Bash для Linux.

## Возможности

Программа позволяет:

- регистрировать преподавателей;
- выполнять вход по логину и паролю;
- создавать и удалять курсы;
- создавать и удалять учебные группы;
- добавлять студентов;
- искать студентов по имени;
- удалять студентов;
- ставить оценки от 2 до 5;
- просматривать оценки;
- удалять оценки;
- отмечать пропуски занятий;
- просматривать пропуски;
- удалять пропуски;
- выполнять выборку по имени;
- выполнять выборку по оценке;
- импортировать студентов из CSV;
- экспортировать данные в CSV;
- создавать резервные копии;
- вести журнал событий;
- работать в интерактивном режиме;
- работать через аргументы командной строки.

## Требования

Для работы необходима Linux-система с Bash.

Используются стандартные утилиты Linux:

- awk;
- grep;
- cut;
- sha256sum;
- tar;
- date;
- sed;
- wc.
